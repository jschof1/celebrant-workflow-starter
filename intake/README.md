# Intake Folder

This folder is for raw client material.

Use `raw-client-files/` for anything supplied by the client or pulled from related folders.

Use `working-notes/` for temporary notes, extraction drafts, or rough summaries while you create the canonical docs in `../docs/`.

## Allowed Mess

This folder can contain:

- duplicate files
- badly named exports
- mixed file types
- old versions
- screenshots
- scattered brand assets

That is fine.

Do not treat this folder as the final system of record.

The goal is to extract what matters into the templates in `docs/templates/`.
