# Celebrant Workflow Reference

## Important Files

- `guide.html`: visual handoff guide for humans and agents
- `AGENTS.md`: repo-wide workflow instructions
- `GEMINI.md`: short setup note for Gemini-style tools
- `docs/celebrant-website-guidelines.md`: default celebrant rules
- `docs/workflow-overview.md`: end-to-end process
- `docs/intake-guide.md`: messy-folder handling guidance

## Template Set

Use `docs/templates/` to create the canonical project docs:

- `client-brief.template.md`
- `reference-analysis.template.md`
- `design-system.template.md`
- `master-prompt.template.md`
- `build-prompt.template.md`
- `brochure-plan.template.md`

## Folder Roles

- `intake/raw-client-files/`: raw client materials
- `intake/working-notes/`: temporary extraction notes
- `docs/`: canonical project documents
- `site/`: website implementation
- `brochure/`: brochure workflow and templates

## Working Principle

The docs define the project.

The skill defines the method.
