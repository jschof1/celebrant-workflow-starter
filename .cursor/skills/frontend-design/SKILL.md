# Frontend Design

Use this skill when building or refining the website UI in `site/`.

## Read First

Before making design decisions, read:

1. `AGENTS.md`
2. `docs/celebrant-website-guidelines.md`
3. `design-system.md` if it exists
4. `build-prompt.md` if it exists

## Core Standard

Do not produce generic template aesthetics.

The design should feel bespoke to the celebrant, based on their real copy, references, imagery, and ceremony mix.

## Design Direction

Commit to a clear point of view.

Good directions for celebrant work include:

- editorial and romantic
- bold and organic
- warm and atmospheric
- refined and modern
- feminine and characterful

Do not default to flat SaaS styling or timid white-card layouts.

## Requirements

- preserve supplied client voice where possible
- use stronger composition rather than rewriting everything
- favour layered backgrounds, asymmetry, overlap, and rhythm
- keep text readable
- make mobile layouts feel intentional, not collapsed desktop leftovers

## Typography

- use a distinctive display face and a readable body face
- avoid bland defaults unless the project specifically demands them
- let headings carry personality

## Motion

- use visible motion thoughtfully
- keep native browser scroll unless the project explicitly requires something else
- reduce heavy effects on mobile

## Repo-Specific Rules

Always follow `docs/celebrant-website-guidelines.md`.

In particular:

- British English
- no accidental em dashes
- no priests in imagery
- no obvious copy duplication across pages

## Quality Bar

The result should feel designed, not generated.
