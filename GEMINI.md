# Gemini Workflow Notes

If you are using this repository in Gemini or another agentic coding tool, start with:

1. `guide.html`
2. `AGENTS.md`
3. `docs/celebrant-website-guidelines.md`

Then load the project-local skills as needed:

- `.cursor/skills/celebrant-workflow/SKILL.md`
- `.cursor/skills/frontend-design/SKILL.md`
- `.cursor/skills/awwwwards-animations/SKILL.md`
- `.cursor/skills/brochure-generator/SKILL.md`

The repo is designed so the docs define the project and the skill defines the working method.

Do not jump straight into `site/` without first reading the docs layer.
