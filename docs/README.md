# Docs Index

The `docs/` folder is the canonical project layer for each celebrant build.

## Core Files

- `celebrant-website-guidelines.md`: default rules for all celebrant projects unless the client brief clearly overrides them
- `workflow-overview.md`: the end-to-end workflow from messy intake to website and brochure delivery
- `intake-guide.md`: how to handle raw folders, duplicate files, partial briefs, and uneven assets

## Templates

Use the files in `templates/` to create the working project documents:

- `client-brief.template.md`
- `reference-analysis.template.md`
- `design-system.template.md`
- `master-prompt.template.md`
- `build-prompt.template.md`
- `brochure-plan.template.md`

## Working Rule

If the raw client folder says one thing and the filled-in canonical docs say another, the canonical docs win.
