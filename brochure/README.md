# Brochure Workflow

Use the brochure stage after the website structure, design direction, and core copy are stable.

## Inputs

The brochure should be based on:

- the canonical brief
- the reference analysis
- the design system
- the website copy and imagery

## Default Rules

- keep British English
- do not introduce em dashes
- make each panel feel visually full
- use one image per service card
- use richer ceremony imagery where possible
- avoid decorative CSS that imports badly into Affinity or similar tools

## Print-Safe Reminder

Be careful with:

- `box-shadow` on non-image wrappers
- decorative pseudo-elements
- invisible or semi-transparent container backgrounds
- unnecessary clipping effects on wrapper elements

## Output Expectation

The brochure should be:

- self-contained
- visually full
- clearly tied to the site design system
- safe to open in vector tools for final production edits
